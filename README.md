# Tidepool Pediatric Therapy

A fictional pediatric therapy clinic website in Santa Cruz, CA. Portfolio piece by Stephen Fehon.

- 28 static pages, no frameworks, no build step, no analytics, no cookies
- Self-hosted Quicksand + Karla variable WOFF2
- Coastal-calm identity: warm shell paper, seafoam/sage, coral accent, deep ink-teal text (WCAG AA)
- Token-based CSS, scroll-driven animations with IntersectionObserver fallback, reduced-motion honored
- `_headers` + `_redirects`, sitemap, robots, llms.txt, OG tags

Live: https://tidepool.pages.dev

All content fictional. Demo forms transmit nothing.
